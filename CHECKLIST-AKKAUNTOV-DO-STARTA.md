# Чек-лист аккаунтов до старта курса

Проверить **до первой пары**, а не во время урока.

## GitBucket

- [ ] У каждого ученика есть аккаунт.
- [ ] Ученик знает логин.
- [ ] Ученик знает пароль.
- [ ] Проверена почта, если требуется подтверждение.
- [ ] Понятно, как восстановить пароль.
- [ ] 2FA не создаёт блокер для школьных компьютеров.
- [ ] GitBucket открывается из школьной сети.
- [ ] Можно одновременно войти группе учеников.
- [ ] У преподавателя есть список логинов учеников.
- [ ] Понятно, что делать, если ученик забыл пароль.

## AI-сервис

- [ ] Выбран основной допустимый сервис.
- [ ] Проверено возрастное ограничение сервиса.
- [ ] Ученик может войти без оплаты.
- [ ] Сервис открывается из школьной сети.
- [ ] Не требуется личная банковская карта.
- [ ] Проверены лимиты использования.
- [ ] Проверено, что группа может пользоваться одновременно.
- [ ] Есть резервный допустимый AI-сервис или заранее подготовленные шаблоны.

## Школьный компьютер

- [ ] Ученик может создать папку.
- [ ] Ученик может сохранить `index.html`.
- [ ] Файлы не удаляются автоматически сразу после выхода.
- [ ] Есть браузер.
- [ ] Есть простой редактор текста/кода.
- [ ] Понятно, где ученик хранит проект между занятиями.

## За день до курса

Сам преподаватель за школьным компьютером проходит:
1. вход в AI;
2. создание файла;
3. открытие страницы;
4. вход в GitBucket;
5. commit;
6. push.

Если любой из этих шагов неожиданно блокируется — исправить до занятия.
