# Курс «Исторический сайт» — версия для полного нуля — v1.0 PILOT

Эта версия учитывает:
- школьники с **нулевым IT-опытом**;
- преподаватель ведёт занятия впервые;
- первые занятия работают только с `Исторический-сайт/index.html`;
- GitBucket объясняется только как `repository → commit → push`;
- перед большой AI-правкой действует ритуал **COMMIT**;
- одна историческая визуализация обязательна; интерактивность для 🟢 минимума не требуется, второй сложный элемент — только для быстрых;
- есть уровни 🟢 минимум / 🔵 нормальный / 🟣 повышенный;
- есть аварийный шаблон таймлайна;
- есть отдельный демонстрационный проект преподавателя;
- домашка помогает, но отсутствие домашки не ломает следующую пару.

## С чего начать преподавателю

1. `00-OBSHIY-PLAN.md`
2. `DEMO-PROEKT-PREPODAVATELYA.md`
3. Файл нужной пары.
4. Перед занятием самостоятельно пройти действия ученика один раз.

## Дополнительный файл

## Новое в v3

- итоговая рубрика оценки на 100 баллов;
- обязательный раздел **«Вывод»** — ответ на исторический вопрос проекта;
- единые правила качества источников;
- AI прямо зафиксирован как **не исторический источник**;
- обязательный элемент теперь называется **историческая визуализация**, а не обязательно сложный JS-интерактив;
- на защите ученик показывает одну вещь в коде, которую умеет изменить сам;
- добавлен отдельный чек-лист технической проверки GitBucket до старта курса.


## Финальная синхронизация v3.1

В этой версии убраны последние противоречия:
- везде обязательна **историческая визуализация**, а не обязательно интерактив;
- источники единообразно: 🟢 3 / 🔵 5+ / 🟣 5+ и первичный;
- изображения должны помогать понять историю;
- перед откатом или шаблоном ученик сначала называет проблему и делает одну простую проверку.


## Статус версии

**v1.0 — пилотная версия курса.**

Архитектура курса считается зафиксированной. Дальше изменения вносятся только по наблюдениям после реальных занятий:
- где ученики застревают;
- сколько реально занимает демонстрация;
- какие инструкции непонятны;
- где преподавателю не хватает запасного сценария.
